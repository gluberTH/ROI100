# ROI // 100 — Операция «Отбить Сотку»

Тактический карточный симулятор ИИ-агента на самоокупаемости.  
Владелец подписки (`@vibe_coder_max`) потратил **$100** из семейного бюджета на топовый тариф нейросети и поставил жёсткий промпт: **отбить $100.00 за 30 дней**, не спалив месячный лимит токенов и не доведя пользователя до отмены подписки своими галлюцинациями.

Игра написана на чистом **HTML + CSS + Vanilla JS** в одном портативном файле `index.html` без внешних зависимостей и полностью адаптирована под мобильные экраны и деплой на **GitHub Pages**.

---

## 🎮 Ключевые особенности

- **Двойная система ресурсов:**
  - **Дневной контекст (`CTX`)** — обновляется каждое утро; тратится на выполнение задач, сжатие контекста (`/compact`) и обновление пула карточек.
  - **Месячный пул Fast-токенов (`1000 TKN`)** — единый запас на все 30 дней. При его исчерпании агент падает с `SONNET-ULTRA-4` на бесплатную урезанную модель `LLAMA-8B-FREE [THROTTLED]` с резким ростом риска сбоев (`+32%`).
- **Риск галлюцинаций и Доверие юзера:**
  - Каждая выполненная задача нагревает контекст и повышает риск галлюцинации. Срыв задачи бьёт по доверию владельца подписки (при `0%` доверия игра заканчивается досрочно) и может повлечь денежный штраф на рискованных контрактах.
  - Команда `/compact` очищает мусор контекста и снижает вероятность сбоя.
- **250 уникальных карточек задач без повторов:**
  - **155 карточек `[ФРИЛАНС]`** — разбиты на 3 тира сложности и оплаты (Дни 1–8: Микро-заказы, Дни 9–18: Миддл, Дни 19–30: Сеньор-контракты).
  - **40 карточек `[АВАНТЮРА]`** — хакатоны, BugBounty, ночные хотфиксы и арбитраж с крупным кушем, высоким риском сбоя и штрафом за провал.
  - **30 карточек `[SAAS-ДЕМОН]`** — микро-сервисы и боты, приносящие пассивный доход каждый день, но требующие свободных слотов и ежедневного расхода токенов (`TKN/день`) на инференс.
  - **25 карточек `[MCP АПГРЕЙД]`** — постоянные системные модификаторы (`Prompt Caching`, `RAG`, `AST-навигация`, `Pre-commit линтеры`, расширение слотов SaaS), снижающие расход токенов, уменьшающие риск галлюцинаций и повышающие выплаты.
  - **Кросс-игровая память:** показанные карточки сохраняются в `localStorage`, поэтому задачи не повторяются ни внутри 30-дневной сессии, ни при старте следующей партии.
- **Живая телеметрия и интерактивные SVG-графики:**
  - График кривой окупаемости (`$` против линии плана `$100`) с расчётом прогноза (`Run-Rate`) к 30-му дню.
  - График расхода пула токенов (`%`) и динамики риска галлюцинаций с поддержкой тач-свайпа и наведения курсора по дням.
- **Процедурный звук (`Web Audio API`):**
  - Встроенный синтезатор звуковых эффектов (клики, выплаты, апгрейды, сбои, фанфары победы) с кнопкой `Mute` и без внешних аудиофайлов.

## 🚀 Запуск и деплой на GitHub Pages

Проект не требует сборщиков (`Webpack`, `Vite`, `npm install`):

1. **Локальный запуск:** просто открой `index.html` в любом современном браузере.
2. **Публикация на GitHub Pages:**
   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial release: ROI // 100 AI Agent Simulator"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
   git push -u origin main
   ```
   Затем в настройках репозитория на GitHub открой **Settings → Pages**, выбери ветку `main` (`/root`) и нажми **Save**.
